# Webhook Processor

Сервис приёма вебхуков с собственной очередью задач на SQLite.

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск сервера

```bash
python app.py
```

### 3. Запуск воркера

```bash
python queue_worker.py
```

### 4. Запуск тестов

```bash
pytest tests/test_webhook.py -v
```

### 5. Доп информация

Принял решение написать проект на FastAPI, так как это мой основной фреймворк для работы.
Для работы с БД использовал контекстный менеджер.
Отдельный асинхронный воркер.
